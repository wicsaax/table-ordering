# v0.2 小餐馆简化版更新

适用于已经安装在 `/opt/jjjshop-dining`、8081端口的接单版。此次仅更新应用代码，不修改数据库表，不覆盖菜单、价格、订单、桌码或密码。

## 变化

- 同一商品大小份合并成一张菜品卡，点击后选择份量。
- 口味默认按原做法；辣度可选不辣、微辣、中辣、特辣，盐量可选少盐，香菜/葱可选不要。其他要求保留备注。
- 同一规格不同口味分别计入购物车、订单快照，价格相同；服务端仍按规格汇总校验库存与数量。
- 顾客扫码自动开桌，不用老板先操作。
- 老板主页只保留看单、全部上齐了、清台；设置折叠。
- 加菜单独标注；已上齐订单收起，可展开并恢复待上菜。
- 清台确认客人已经付款离店，保存旧账单；新客人扫码开始新的一次用餐。
- 店员设备登录保持最多30天（更新后需重新登录一次）；声音仍需点开启且保持页面打开，不保证锁屏提醒。

## 在服务器更新（无需Token）

```bash
cd /root/table-ordering &&
GIT_TERMINAL_PROMPT=0 timeout 300s git -c credential.helper= pull --ff-only https://ghfast.top/https://github.com/wicsaax/table-ordering.git main &&
bash updates/v0.2/update.sh
```

完成后刷新顾客页、店员页即可。原代码自动备份到 `/var/backups/jjjshop-dining/update-时间/`。无需再运行首次安装脚本。

## 已验证

PHP、JavaScript、Shell语法通过。真实MariaDB的24项既有回归检查通过；新增自动开桌、规格分组标识、加菜批次、直接上齐/撤销、清台隔离、口味快照、口味不改变价格、口味重试去重、非法选项拒绝、跨口味数量/库存汇总检查通过。
浏览器验证：单道菜只显示一张卡，弹窗默认份量/口味，选择微辣和不要香菜后正确显示；老板页面按桌展示不同口味订单。
Ubuntu上的更新脚本尚需用户实际执行验证。无在线支付和锁屏推送功能。
