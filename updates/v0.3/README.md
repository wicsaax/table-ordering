# v0.3 桌台首页与统一菜品设置

## 老板首页

登录后默认显示全部桌台，包括空桌。桌卡显示桌号、状态、订单数、金额和待上菜数量。点任意桌卡，在原页弹窗看该桌菜品、份量、口味、备注；可点全部上齐、恢复误点、收款离店后清台。空桌点击只查看，不开桌；顾客扫码自动开桌。

首页保留打印桌码、声音提醒、折叠设置入口。日常不用切换“看订单/桌台详情”，没有手动开桌按钮。打印桌码可返回桌台。

## 菜品设置统一按菜管理

设置 → 菜品设置，每道菜只有一张卡。点进去一次设置：

- 菜名；各份量名称、价格、可售状态和默认份量。
- 添加新份量；不再卖的份量取消可售，保留历史关联。
- 是否让顾客选择辣度、盐量、香菜、葱。
- 每类口味允许的选项和默认值（例如微辣默认、不展示香菜选择）。

顾客端读取同一份配置，选菜时显示对应份量和口味。默认份量售罄时自动选择第一个可售份量。调整不会改变历史订单快照。既有口味类型内可开关选项；本版不支持自建新的口味类型或额外口味加价。
